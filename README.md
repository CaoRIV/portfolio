## Overview

This portfolio presents a personal story through an engaging, interactive experience. The design is clean and modern, with a focus on visual storytelling and smooth user interactions.

## ✨ Features

- **Hero Section** – Introduction with name, location, and call-to-action buttons
- **About Section** – Overview of working approach and interests
- **Skills Section** – Key technical skills
- **Projects Section** – Featured work and projects
- **Timeline** – Learning journey and milestones
- **Contact Section** – Email, social links, and contact form
- **Responsive Design** – Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations** – Interactive transitions with Framer Motion

## 🎨 Design

The site uses:
- Warm, editorial color palette
- Large, expressive typography
- Smooth animations and hover effects
- Fully responsive design for desktop and mobile
- Modern product storytelling inspiration

## 🛠️ Tech Stack

- **[React](https://react.dev)** – Component structure
- **[Vite](https://vitejs.dev)** – Fast frontend build tool
- **[Framer Motion](https://www.framer.com/motion)** – Smooth animations and scroll effects
- **CSS** – Layout and styling

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/CaoRIV/portfolio.git
cd portfolio
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The application will be available at `http://127.0.0.1:5173`

### Production Build

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
