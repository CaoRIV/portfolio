# Cao Van Ha Portfolio

A one-page portfolio for Cao Van Ha, an AI Engineer focused on RAG systems, Vietnamese NLP, educational technology, and full-stack AI products.

## Highlights

- Hero section with role, availability, and animated system map
- Featured case studies and project showcases
- Clear process overview: Discover, Design, Build, Validate
- Skills, experience, and contact information

## Tech Stack

- React 19
- Vite 6
- Framer Motion 12
- Plain CSS
- Playwright Core

## Development

```bash
pnpm install
pnpm dev
```

Build for production:

```bash
pnpm build
```

Run visual checks:

```bash
node scripts/visual-check.mjs
```
